# 🐧 my_scripts

This repo contains some basic **shell scripts** I created while learning Linux. If you're new to shell scripting or DevOps, these examples can help you understand how things work.

## 📜 What's Inside

- **case_script.sh**  
  Shows how to use a `case` statement to handle multiple choices, like a switch-case in other languages.

- **file_iterate.sh**  
  Reads through files line-by-line or loops through a list of files. Great for batch file operations.

- **forloop.sh**  
  A simple example of using a `for` loop to repeat a task multiple times.

- **if_else.sh**  
  Demonstrates how to use `if`, `else`, and `elif` statements to make decisions in a script.

- **user_input.sh**  
  Takes input from the user and does something with it. Helps understand how `read` works.

- **variable.sh**  
  Shows how to create and use variables in a shell script.

- **while.sh**  
  Runs a block of code while a condition is true — an intro to `while` loops.
